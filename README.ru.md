# LLMLINK Cinema 4D

Первая рабочая alpha-версия для **Cinema 4D 2024.2 на macOS**. Панель чата находится внутри Cinema 4D и закрепляется в рабочем пространстве штатными средствами редактора.

## Начать работу

1. Сохрани сцену. Распакуй установочный архив и запусти `Install.command`.
2. Перезапусти Cinema 4D. Открой **Extensions → LLMLINK**.
3. Выбери **Codex** или **LM Studio**, нажми **Connect**.
4. Выбери модель и **Thinking**. Доступные уровни берутся из каталога выбранной модели.
5. Введи задачу и нажми **Send / Queue**.

Для Codex используется авторизация установленного официального клиента. Для LM Studio нужно загрузить модель с поддержкой инструментов и включить локальный сервер. Обычный адрес — `http://127.0.0.1:1234/v1`; его можно изменить в **Settings**.

## Управление

**Manual apply**: модель предлагает шаг. **View code** показывает Python; **Apply change** применяет его, **Decline** отклоняет. **Auto apply** применяет последующие шаги автоматически. Режим можно менять во время работы.

Пока задача выполняется, отправляй следующие сообщения — они попадут в последовательную очередь. **Run next** переносит выбранную задачу вперёд; **Steer** уточняет текущую задачу после завершения уже начатого шага. **Stop** останавливает дальнейшие шаги и ставит очередь на паузу. **Resume** продолжает очередь.

**+ File** добавляет изображение или файл. Название вложения остаётся рядом с сообщением. Возможность анализа изображения зависит от модели. **New chat / Open chat** управляют сохранённой историей.

## Что можно поручать

- Создание и изменение объектов, полигональной геометрии, материалов, света и камер.
- Создание ключей анимации через Python API Cinema 4D.
- Рендер отдельного кадра через `llmlink.render()` с подтверждённым сохранением PNG.
- Сохранение новой копии сцены через `llmlink.save_scene()`.

Например: «Создай небольшой дом с двускатной крышей, добавь камеру и свет. Сделай рендер 640×480 и сохрани копию сцены».

## Файлы и ограничения alpha

Перед каждым шагом изменения сохраняется контрольная копия `.c4d`. История, очередь, контрольные копии и результаты находятся отдельно от плагина, в папке `LLMLINK` внутри пользовательских настроек Cinema (`C4D_PATH_PREFS`). На проверенной установке это `prefs/LLMLINK`.

Сгенерированный Python выполняется с правами Cinema 4D и не является изолированной средой. Для важных сцен используй Manual apply и отдельную резервную копию.

Проверен встроенный Standard renderer. Для активного рендера сцены предусмотрен `engine="current"`, но Redshift и сторонние движки пока не проверены. Отдельный интерфейс пакетного рендера анимации и управления симуляциями в эту версию не включён. Другие версии Cinema 4D и Windows ещё не проверены.

Примеры результата находятся в `examples/`. Подробности установки, разработки и проверки — в [README.md](README.md) и [docs/VALIDATION.md](docs/VALIDATION.md).

## Длинные чаты

Чат не ограничен числом запросов. Рабочий контекст модели отделён от полного локального архива: повторные снимки сцены и большие технические распечатки сокращаются, старые шаги автоматически переходят в сохраняемую память. Последний запрос, актуальная сцена и код незавершённого шага остаются в рабочем контексте. Модель может искать прежние требования через `recall`. Создавать новый чат из-за заполнения истории больше не требуется. Память является кратким пересказом, поэтому перед изменениями модель проверяет настоящую сцену.

## Проверка стабильности 0.2.0

[Отчёт аудита](docs/RELEASE_AUDIT.md) описывает исправления, результаты испытаний и оставшиеся условия публичного релиза. Добавлены проверки кода перед исполнением, восстановление подключения, защита черновиков, фиксация начала задания перед удалением из очереди и привязка очереди к документу. Импорт 3D-файла выполняется через `llmlink.import_asset(path)` только для файла, явно прикреплённого к текущему сообщению. Проверки Python не являются полной изоляцией от Cinema 4D и её нативных расширений.
